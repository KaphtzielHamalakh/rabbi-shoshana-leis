# Rabbi Shoshana Leis

Starter personal website for Rabbi Shoshana Leis, published with GitHub Pages at [rabbishoshanaleis.com](https://rabbishoshanaleis.com).

## Editing the site

The current site is a single self-contained page in `index.html`; its styles are included in the document for easy editing. Update the text and styles there, then commit the changes to `main`.

## GitHub Pages and the domain

In the repository, open **Settings → Pages** and publish from the `main` branch, root folder. The custom domain is stored in `CNAME`.

At Porkbun, set the root domain's four GitHub Pages A records and a `www` CNAME pointing to `KaphtzielHamalakh.github.io`. DNS propagation and GitHub's HTTPS certificate can take some time after the records are saved.
